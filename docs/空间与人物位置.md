# 空间关系和人物位置

## 两种用法

**相对某物的位置**是可续写半句，选中后留空格、不加逗号，再补具体物体。例如 `zuojiaofangzaipangbian` 输出 `left foot resting beside `。

**人物在画面里的位置**是完整短语，选中后正常加逗号。例如 `renwuzaihuamianzuoce` 输出 `character on the left side of the frame, `。

角色自身的左腿、右脚，与物体左侧、画面左侧是不同含义。它们分别在英文中写清楚。

输入顺序是“位置半句 → 物体”，例如先选“脚在某物左侧”，再选“浴缸”。不能先提交物体，再接方位词来自动换序；具体例子见[浴缸位置连接](浴缸位置连接.md)。

## 常用例子

| 输入 | 含义 | 英文输出 |
|---|---|---|
| `shangmian` | 在某物上面，继续填物体 | `on ` |
| `renwuzuozaishangmian` | 人物坐在某物上面 | `character sitting on ` |
| `pangbian` / `bianshang` | 在某物旁边／边上，继续填物体 | `beside ` |
| `zuojiaofangzaipangbian` | 左脚在某物旁边 | `left foot resting beside ` |
| `youjiaofangzaiqianmian` | 右脚在某物前面 | `right foot resting in front of ` |
| `zuotuifangzaihoumian` | 左腿在某物后面 | `left leg resting behind ` |
| `youjiaofangzaixiamian` | 右脚在某物下面 | `right foot resting under ` |
| `zuojiaofangzaishangfang` | 左脚位于某物上方，不表示接触 | `left foot positioned above ` |
| `youjiaofangzaizuoce` | 右脚在某物左侧 | `right foot positioned to the left of ` |
| `renwuzhanzaipangbian` | 人物站在某物旁边 | `character standing beside ` |
| `renwuzuozaihoumian` | 人物坐在某物后面 | `character sitting behind ` |
| `renwujuzhong` | 人物在画面中央 | `character centered in the frame, ` |
| `renwuzaihuamianzuoce` | 人物在画面左侧 | `character on the left side of the frame, ` |
| `renwuzaihuamianyoushangjiao` | 人物在画面右上角 | `character in the upper right corner of the frame, ` |
| `renwuzaiqianjing` | 人物在前景 | `character in the foreground, ` |
| `renwuzaibeijing` | 人物在背景 | `character in the background, ` |

“放在……上”用 on，通常表示接触或支撑；“位于……上方”用 above，只表示相对位置。between 后面需要补两个对象，例如 `the table and the chair`。

人物相对位置提供“在、站在、坐在、躺在”四种表达；画面位置提供九宫格位置，以及前景、中景、背景、远处和近处。

这些是固定英文描述及可续写半句，不会自动分析场景或替用户选择物体。这些用法自 v0.2.11 起提供。
