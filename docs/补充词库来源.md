# 补充词库来源（0.2.3）

本轮四个补充来源都已转换。只读取固定版本的文本数据，不运行上游代码、不部署 WebUI 扩展、MCP、向量数据库或翻译服务。所有词条离线使用；不按主模型版本屏蔽。原始文件 URL、SHA-256、字节数及转换统计记录在 `data/library_sources.json`，转换结果为 `data/imported_terms.tsv.gz`。

n714读取3,291条叶子记录，接受2,970条中文别名映射；Physton读取3,981条 tags 记录，接受3,707条别名映射。接受数在来源内和跨来源去重前统计，不等于净新增数。仅导入有纯中文检索别名的短词/短语，排除整组逗号提示词、带显式权重或其他模板标记的内容。单词外平衡的强调括号去掉后导入普通词，内含字面括号仍由上屏层转义。Physton源文件说明中文由机翻生成，并署名“路过银河（知乎）、未知作者（Google Drive）、互联网”等整合来源；本项目保留原快照与说明，不宣称这些译名经过人工校对或是Physton原创。

MTT共87,670行，拆分中文别名后排除151个被超过64个不同英文词共享的泛分类别名，例如“服装”“游戏”；它们会造成大量无关候选。其余中文别名生成182,214条接受记录，自动拼音未逐条审读，不猜译混合英文/数字的释义。

e621文件没有表头，共149,253个英文标签。按规范标签或源表显式英文别名连接MTT中文，共35,517个e621标签获得中文映射，113,736个未获得，不能把整个英文归档称为已支持中文输入。连接接受121,139条别名记录，随后跨来源去重。

最终补充数据为73,988个词条键／192,878条映射，来源记录保留历史分层统计：一般类与物种类范围47,125个键／137,213条映射，其余类别也已纳入当前唯一的完整默认库。n714和Physton短语同样全部纳入。运行库合并同拼音同最终英文的重复行，候选层也按最终英文去重；原始来源与许可不删改。

未筛除成人相关标签。质量词只是可输入的常见表达，不承诺适用于每个模型或必然改善图片；负面词要手动放入负面输入框。
