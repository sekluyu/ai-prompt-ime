# 开发与发布

当前0.2.3已采用完整词库作为唯一默认，不产出-searchable公开附件。开发测试使用隔离目录，真实用户目录的安装/部署由使用者明确授权；实际输入和图像效果由维护者验收。后续发布仍需维护者明确批准。

## 构建

普通用户使用独立EXE，不需要Python/.NET/Go。开发者用Python运行构建脚本；源码中的rime为当前完整默认库。

`python tools/build.py --source rime/booru.tsv` 可重复重建完整运行库。历史bootstrap入口不带--source时仅含演示基础词，不应用于正式交付。若需从原始来源重建，先准备dictionary目录与固定ffdkj快照，按convert_dictionary.py要求安装pypinyin 0.55.0并转换，再以entries.tsv构建。dictionary与开发依赖不进入Git。

补充来源导入使用pypinyin 0.55.0和PyYAML 6.0.3；固定文本URL和SHA在data/library_sources.json。保存为快照目录的source/path及snapshot.json后运行 `python tools/import_prompt_libraries.py --snapshot <快照目录>`。不执行上游代码，不部署WebUI/MCP服务。构建读取imported_terms.tsv.gz只用Python标准库。

构建默认加载完整来源范围；`--variant default`仅供历史小范围开发对照，不是公开第二版本。原始来源只读；生成时先按内部键保持既有顺序，再合并同拼音同最终英文的重复项。候选Lua另外按最终上屏文本去重。

## 检查与边界

本轮数据核对：`python tests/deduplication_test.py --before <更新前完整booru.tsv> --output-dir <本地审核目录>`，确认检索/英文覆盖、最大权重和输出唯一性，生成完全重复合并清单与空格/下划线待审核清单。before必须是去重前完整基线，不要覆盖它。

`python tests/lua_filter_test.py`借用自备librime DLL导出的Lua API执行模拟候选流，不创建Rime会话、不发送按键；需用BOORU_RIME_DIST指定含lib/rime.dll的目录。仓库不捆绑DLL。它生成lua-filter-unit.json，和数据核对报告一起记录当前TSV/Lua的SHA。

此前engine_test.py、color_phrases_test.py、prompt_libraries_test.py仍保留为开发集成入口，自备引擎和头文件；engine_test还需psutil。测试目录必须隔离，BOORU_TEST_SOURCE/USER/LOG可指定。按老板当前分工不再代跑输入/选词测试。Comfy smoke会提交本机生成任务，不属于默认检查，未经明确同意不运行。

## 安装器与打包

Go原生安装器只用标准库，目标Windows x64。`python tools/build_windows_installer.py --go <go.exe> --source rime --output <EXE>`；Go 1.23以上只供开发。--test可跑安装器单元测试，不属于用户安装依赖。

`python tools/package_release.py --artifacts-root <保留数据根目录> --validation-root <报告目录> --prompt-snapshot <固定四源文本目录> --go <go.exe> --output-dir <本地附件目录>`生成一个独立EXE、方案ZIP、追溯ZIP和SHA256SUMS。当前0.2.4需要匹配TSV/原生词典的ranking-slang.json与匹配Lua的lua-filter-unit.json；此前引擎报告仅作为历史基线；打包区分当前数据/Lua检查和历史引擎证据，不把旧报告冒称新版本实机验收。

每个ZIP带内部校验清单及完整许可；词库追溯包不用于安装，不含已清理的大型再生文件。打包后核对CRC、内部哈希及内置EXE一致性。原Python安装/回滚入口保留，独立EXE不依赖它。保留用户原配置和安装器备份，不为清理删除真实用户数据。

v0.2.4经维护者指示先发布基础更新及独立EXE；方案ZIP包含同一安装器、rime、文档、许可和当前检查证据，并校验CRC、内部哈希、外部SHA256与EXE一致性。本轮不重新打包原始数据追溯ZIP。后续发布仍需维护者明确指示。源码不包含EXE/ZIP、引擎DLL/PDB/7z、原始数据库、缓存、日志、密钥或本机路径报告。
