# 开发与发布

当前v0.2.6采用完整词库作为唯一默认，不产出-searchable公开附件。开发测试使用隔离目录，真实用户目录的安装/部署由使用者明确授权；实际输入和图像效果由维护者验收。后续发布仍需维护者明确批准。

## 构建

普通用户使用独立EXE，不需要Python/.NET/Go。开发者用Python运行构建脚本；源码中的rime为当前完整默认库。

`python tools/build.py` 默认读取现有 `rime/booru.tsv`，重复重建完整运行库；也可显式指定 `--source <TSV>`。检查构建结果时用 `--output-dir <隔离目录>`，build.json也写入该目录，保留正式验证报告。演示入口必须显式使用 `--demo --output-dir <独立目录>`，不得输出到项目rime目录；缺少完整源文件时直接报错，不回退为演示库。若需从原始来源重建，先准备dictionary目录与固定ffdkj快照，按convert_dictionary.py要求安装pypinyin 0.55.0并转换，再以entries.tsv构建。dictionary与开发依赖不进入Git。

补充来源导入使用pypinyin 0.55.0和PyYAML 6.0.3；固定文本URL和SHA在data/library_sources.json。保存为快照目录的source/path及snapshot.json后运行 `python tools/import_prompt_libraries.py --snapshot <快照目录>`。不执行上游代码，不部署WebUI/MCP服务。构建读取imported_terms.tsv.gz只用Python标准库。

构建默认加载完整来源范围；`--variant default`仅供历史小范围开发对照，不是公开第二版本。原始来源只读；生成时先按内部键保持既有顺序，再合并同拼音同最终英文的重复项。候选Lua另外按最终上屏文本去重。

## 检查与边界

本轮数据核对：`python tests/deduplication_test.py --before <更新前完整booru.tsv> --output-dir <本地审核目录>`，确认检索/英文覆盖、最大权重和输出唯一性，生成完全重复合并清单与空格/下划线待审核清单。before必须是去重前完整基线，不要覆盖它。

`python tests/lua_filter_test.py`借用自备librime DLL导出的Lua API执行模拟候选流，不创建Rime会话、不发送按键；需用BOORU_RIME_DIST指定含lib/rime.dll的目录。仓库不捆绑DLL。它生成lua-filter-unit.json，和数据核对报告一起记录当前TSV/Lua的SHA。

此前engine_test.py、color_phrases_test.py、prompt_libraries_test.py仍保留为开发集成入口，自备引擎和头文件；engine_test还需psutil。测试目录必须隔离，BOORU_TEST_SOURCE/USER/LOG可指定。真实用户目录的输入/选词检查按维护者授权进行。Comfy smoke会提交本机生成任务，不属于默认检查，未经明确同意不运行。

维护入口回归检查：`python tests/maintenance_test.py --installer <已验收EXE> --go <go.exe> -v`。覆盖完整库重复构建、演示目录限制、版本不一致拒绝，以及复用/编译EXE的隔离打包、可选追溯包和包内外哈希；未提供EXE或Go参数时，对应集成检查会明确跳过。

## 安装器与打包

Go原生安装器只用标准库，目标Windows x64。`python tools/build_windows_installer.py --go <go.exe> --source rime --output <EXE>`；Go 1.23以上只供开发。--test可跑安装器单元测试，不属于用户安装依赖。

`python tools/package_release.py --installer <已验收EXE> --validation-root <报告目录> --output-dir <新的本地附件目录>` 默认生成独立EXE、含相同EXE的方案ZIP与SHA256SUMS，不需要原始dictionary目录。复用时在临时用户目录核对EXE版本、完整默认库标识、四个方案文件和内置许可；不更改真实Rime目录，不重新编译EXE。未传 `--installer` 时用 `--go <go.exe>` 编译新EXE，新文件仍需重新验收与扫描。

打包前检查schema、词典头、build.py、Go安装器和打包版本一致。需要匹配当前TSV/原生词典的ranking-slang.json、pose-phrases.json及匹配Lua/TSV的lua-filter-unit.json；此前引擎、颜色和短语报告只作为历史baseline。包内说明不把打包动作当作已验收或已发布。需要重新生成追溯包时显式增加 `--include-dictionary --artifacts-root <保留数据根目录> --prompt-snapshot <固定四源文本目录>`；普通更新继续引用已标明版本的历史追溯包。

每个ZIP带内部校验清单及完整许可；词库追溯包不用于安装，不含已清理的大型再生文件。打包后核对CRC、内部哈希及内置EXE一致性。原Python安装/回滚入口保留，独立EXE不依赖它。保留用户原配置和安装器备份，不为清理删除真实用户数据。

历史v0.2.4经维护者指示先发布基础更新及独立EXE；方案ZIP包含同一安装器、rime、文档、许可和当前检查证据，并校验CRC、内部哈希、外部SHA256与EXE一致性。本轮不重新打包原始数据追溯ZIP。后续发布仍需维护者明确指示。源码不包含EXE/ZIP、引擎DLL/PDB/7z、原始数据库、缓存、日志、密钥或本机路径报告。

## v0.2.5内嵌资源格式

构建脚本在临时目录生成确定性的`resources.zip`，仅含`payload/`方案文件和`notices/`许可。使用标准ZIP/DEFLATE、固定条目时间及稳定顺序；没有加密或自定义编码。Go使用`archive/zip`直接按原路径读取，不释放或执行其他程序。读取资源时验证ZIP CRC，安装前读取全部管理文件；错误时拒绝安装。资源ZIP和临时编译目录随构建结束清理，不进入Git。
