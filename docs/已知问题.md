# 已知问题（v0.2.3）

本版已处理相同最终英文的重复候选，以下两类问题仍保留，未冒称已经修复。维护者决定先发布现状，后续另行处理。

## 泛化中文别名与错误注释

[Issue #1：清理“狐狸”等泛化中文别名与错误候选注释](https://github.com/sekluyu/ai-prompt-ime/issues/1)

输入hul/huli时，部分具体狐种、狐妖或角色也被上游挂上“狐狸”别名；fossa等还存在错误注释。它们的英文不同，不应直接作为完全重复项删除。通用词应只检索通用标签，还是保留具体狐种并细化注释，仍待确认。

hul是未完成前缀，补全出hulu（葫芦等）属于正常行为；huli也有“护理”等真正同音词。本问题不意味着禁用所有补全或删去同音词。

## 空格／下划线近似写法

[Issue #2：审核384组空格／下划线近似提示词写法](https://github.com/sekluyu/ai-prompt-ime/issues/2)

white_hair与white hair等384组写法仍保留。当前过滤器只按最终英文完全相同去重，不按近似词义、大小写或标点统一输出。后续需逐组核对来源和用途，保留中文别名入口与来源记录。

以上问题均未在本版进一步删词。反馈时请提供版本、输入拼音和候选英文；不要提交私人路径、日志凭据或含个人信息的截图。
