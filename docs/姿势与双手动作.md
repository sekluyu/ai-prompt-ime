# 姿势与双手动作（v0.2.6）

本轮项目维护层包含324条中文入口：躯干24条、单手216条、常用双手组合84条。相对v0.2.5新增323个检索/英文组合，另1条已有入口更新姿态注释；完整词库276,799条映射，旧版全部检索/英文组合保留。

这些是项目维护的自然语言姿态短语，候选标注“通用姿态”，不冒充全部都是Danbooru/e621规范标签。沿用的`leaning_forward`和`leaning_back`为既有标签写法。它们提供可检索的描述，不保证模型一定遵守左右手、动作或位置。

## 躯干姿态

| 中文入口 | 拼音 | 输出 |
|---|---|---|
| 上半身直立 | shangbanshenzhili | upright torso |
| 上身挺直 | shangshentingzhi | upright torso |
| 坐直 | zuozhi | sitting upright |
| 背部挺直 | beibutingzhi | straight back |
| 上身前倾 | shangshenqianqing | leaning_forward |
| 上身后仰 | shangshenhouyang | leaning_back |

“上半身”对应`upper_body`，主要用于取景范围；“上半身直立”描述姿态，两个概念分开。原有泛称别名继续保留，本轮未作语义删词。

## 分别输入两只手的动作

先输入一个动作并选词，再输入另一个，不需要整句都在词表里：

1. `zuoshoufuyao` → `left hand resting on hip, `。
2. `youshoumotou` → `right hand touching head, `。

合起来为`left hand resting on hip, right hand touching head, `。这样可自由搭配已有动作，不必预先生成所有组合。

支持六种中文开头：左手、右手、一只手、另一只手，以及一手、另一手两个较短入口。英文分别使用`left hand`、`right hand`、`one hand`、`the other hand`。左右描述按角色自身理解，模型仍可能混淆。

动作包括摸头、头发、脸/脸颊、额头、耳朵、口鼻、脖子、肩膀、胸口、腹部、后背、尾巴，以及扶腰、扶膝、托下巴、托腮、遮脸、举手等。摸脸`touching face`、托腮`cupping cheek`和托下巴`supporting chin`分别保留，不统一成“摸”。“摸口鼻”使用`touching muzzle`，适合口鼻部突出的兽类角色。

| 左手摸头右手扶腰 | zuoshoumotouyoushoufuyao | left hand touching head, right hand resting on hip |
| 一只手托下巴另一只手放大腿上 | yizhishoutuoxiabalingyizhishoufangdatuishang | one hand supporting chin, the other hand resting on thigh |

只维护14组常见动作配对及互换顺序，不生成所有动作的笛卡尔积。配对内的英文逗号属于短语原文，Ctrl＋Alt＋F9只影响选词后自动添加的分隔空格，不重写短语内部标点。

## 数据与验收

维护表为`data/pose_phrases.tsv`，格式与普通维护短语相同：english、zh、code、category。由`general_phrases.pose_rows()`加载，按primary进入现有构建和去重流程，不在输入时生成组合或跟踪上一只手。

数据覆盖、英文/拼音唯一性、左右手样例、旧条目保留、原生优先级及Lua模拟候选检查通过。维护者已确认本轮EXE火绒扫描未发现风险，并确认本机输入检查通过；图像效果仍取决于模型。
