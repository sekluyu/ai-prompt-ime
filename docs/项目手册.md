# 项目手册

## 用途

这是 Windows 小狼毫的离线绘画提示词方案。输入中文拼音后选择英文标签或短语，默认加逗号和空格。当前版本为 [v0.2.11](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.11)，共 279,146 条拼音映射。

普通用户运行独立安装器即可，无需 Python、Go、.NET 或 API Key。安装前自动备份受管理文件，安装后需要从小狼毫托盘重新部署。不创建桌面入口。

## 常用操作

- `zhengmian`：选择基础、动漫、写实、兽人毛发或自然肌肉组合。
- `fumian`：选择基础负面、身体结构负面或腹肌负面组合。
- 空格选择第一项，数字键选择候选；`=` 和 `-` 翻页，Esc 取消。
- Ctrl＋Alt＋F9 开关逗号后的空格，逗号保留。短语内部的标点保持原样。

输入法不会自动判断绘图软件的正面或负面框。请先选择输入框再选词。完整组合、补充词和修正清单见[本次词库更新](词库更新-0.2.9.md)。

腿和脚的放置词支持左、右、双侧及多种物体，例子和完整表达见[腿脚放置](腿脚放置.md)。

姿势与位置补充见[基础姿势](基础姿势补充.md)、[可续写短语](可续写短语.md)、[空间与人物位置](空间与人物位置.md)。位置半句按英文顺序先选关系，再补物体，不会自动调换已经输入的片段。

## 文件说明

| 文件 | 用途 |
|---|---|
| `data/general_prompts.tsv` | 原有质量、材质和常用短语 |
| `data/expanded_prompts.tsv` | 本次补充词、自然中文入口和整串组合 |
| `data/term_corrections.tsv` | 已核对的拼音与翻译修正规则 |
| `data/general_colors.tsv` | 颜色和配色 |
| `data/slang_aliases.tsv` | 俗称入口 |
| `data/pose_phrases.tsv` | 姿势和左右手动作 |
| `data/imported_terms.tsv.gz` | 固定上游来源转换数据 |
| `tools/term_repairs.py` | 加载修正规则和补充词 |
| `rime/booru.tsv` | 构建后的完整运行词表，保留原热度 |
| `rime/booru.dict.yaml` | Rime 原生词典，使用编译后的排序权重 |
| `rime/booru.annotations.tsv` | 中文说明索引 |
| `rime/lua/booru_filter.lua` | 中文说明、英文去重和分隔符处理 |

## 修改与检查

在对应 TSV 中维护词条，不直接手改生成词典，也不改写原始来源快照。修正拼音时确认该词的含义，避免机械处理多音字。候选按完整匹配、补全长度、主词与中文分组排序。

运行 `python tools/build.py` 重建当前完整词库。使用 `--output-dir <目录>` 可在独立目录验证重建；演示库必须使用 `--demo --output-dir <独立目录>`。

数据变化后运行词库修复、排序、姿态和来源覆盖检查；Lua、真实引擎及延迟检查需要自备 librime，设置 `BOORU_RIME_DIST` 指向其 dist 目录。测试引擎不随安装包发布。

用 `tools/build_windows_installer.py --go <go.exe> --output <EXE路径> --test` 构建安装器，再用 `tests/native_installer_test.py --exe <EXE路径>` 验证隔离安装和回滚。`tools/package_release.py` 负责打包并核对版本、方案内容和验证记录。

发布前核对 Git 差异、版本号、下载链接和附件哈希。新版本需要自己的测试记录，不能沿用旧 EXE 的安全软件扫描结论。正式发布包含独立 EXE、ZIP 和 SHA256SUMS.txt。

## 本机数据与回滚

安装器备份方案文件及受影响的配置。卸载或回滚前先查看[安装与回滚](安装与回滚.md)，不要手动清理 Rime 下的 `booru-backups`。清理开发临时文件时保留正式包、有效证据、共享工具链和用户备份。

仓库只提交源码、维护词表、生成词库和文档。模型、私人图片、密钥、引擎 DLL、编译缓存和机器路径报告不提交。

识图程序 [AI Prompt Vision](https://github.com/sekluyu/ai-prompt-vision) 独立运行，模型不进入 Rime。建议截图使用 Ctrl＋Alt＋F8，输入法保留 Ctrl＋Alt＋F9。
