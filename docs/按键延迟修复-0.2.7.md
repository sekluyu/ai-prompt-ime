# 按键延迟修复 · v0.2.7候选起，v0.2.8正式纳入

本修复最初在v0.2.7本地候选验证，正式纳入v0.2.8；v0.2.7未单独公开。以下保留候选实验说明，v0.2.8发行前另对当前文件运行性能与全库回归，具体报告随交付记录保留。授权发布不等于已记录新EXE扫描或全部实机输入验收。

## 问题与修改

v0.2.6将276,799条映射的匹配说明及主释义保存在大Lua表中。隔离对照显示，保留这些表时即使过滤器只传递候选，持续按键仍慢；将表移到模块私有变量也无明显改善。具体引擎内部机制未确认。

v0.2.7在构建时生成booru.annotations.tsv，按键排序保存匹配说明、主次标记和回退释义。Lua读取为一块UTF-8文本，对当前候选进行二分查找，不常驻数十万项Lua表。该文件可以从现有TSV确定性重建。

完整TSV、词条和热度不变，原生词典仅更新版本头；注释选择、排序、去重、转义和分隔符保持。文件增加约22.1MiB，不属于新词库或新依赖。

## 三轮隔离性能

每轮每个配置123次操作，包含输入、退格、翻页与选词。所有轮次的候选英文、中文注释、顺序、分页标记和提交内容完全一致。

| 轮次 | v0.2.6 Lua中位数 | 候选中位数 | 候选P95 | 候选最慢 |
|---|---:|---:|---:|---:|
| 1 | 27.709 ms | 0.242 ms | 0.833 ms | 1.086 ms |
| 2 | 30.274 ms | 0.236 ms | 0.898 ms | 1.284 ms |
| 3 | 29.622 ms | 0.237 ms | 0.847 ms | 0.953 ms |

三轮均满足中位数<5ms、P95<10ms。隔离选择方案耗时由约1.00—1.02秒降至约0.071—0.074秒；这是引擎调用时间，不是Windows输入框端到端时间。

## 功能与兼容

- 对照v0.2.6 Lua，完整核对276,799条精确匹配注释，并抽查补全与回退释义。
- 现有Lua模拟检查覆盖跨页重复、同义入口、括号转义、空格/纯标签设置和双手短语。
- 安装器新增管理booru.annotations.tsv，连同原有四个方案文件及default.custom.yaml共六个文件；新备份增加format_version=2。
- 新安装器支持安装到v0.2.6、回滚恢复v0.2.6，再继续回滚旧备份链。旧安装器不用于回滚新格式备份。
- 手动安装必须同时复制新注释文件与对应Lua，不能只替换Lua。

## 候选验收

先对本次独立EXE执行安全软件扫描；获维护者指示后才安装/重新部署真实Rime。实际检查连续输入、退格、翻页、长动作词和聊天/绘图输入框，确认没有明显迟滞且候选符合预期。确认后再决定是否发布。

开发回归命令见《开发与发布》。测试报告仅代表隔离引擎与安装检查，不代表实机输入或模型效果验收。
