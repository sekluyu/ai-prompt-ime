# “脚放在浴缸左侧”怎么输入

目前按片段顺序追加英文，不会自动调换已输入的内容。中文的“脚放在 → 浴缸 → 左侧”不能直接连成正确英文。

请按英文关系先选半句，再补物体：

1. 输入 `jiaofangzaizuoce`，选择“脚在某物左侧”，输出 `one foot positioned to the left of `。
2. 输入 `yugang`，选择“浴缸”，输出 `bathtub, `。

结果是 `one foot positioned to the left of bathtub, `。

指定左脚用 `zuojiaofangzaizuoce`，指定右脚用 `youjiaofangzaizuoce`。前一个“左／右”表示哪只脚，最后的“左侧”表示在浴缸的哪一侧。

`jiaofangzai` 输出的是 `one foot resting on `，表示脚放在某物上，不适合再在物体后面接“左侧”。要表达旁边、左侧、右侧等关系，请先选相应半句，再补物体。若直接手动补英文，可以写 `the bathtub` 并按需加逗号。

本次补齐未指定左右的“脚／腿”空间关系入口，并将具体物体“浴缸”的优先英文改为bathtub。
