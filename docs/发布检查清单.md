# 发布检查清单

v0.2.6已由维护者确认输入检查通过、确认新EXE火绒扫描未发现风险，并明确同意上传。以下流程供每轮发布使用，具体完成情况以该轮证据为准。

- 核对维护词表、许可、来源及成人标签说明；保留原来源快照，不冒充所有机翻已审读。
- 数据检查需保留旧检索/英文组合；本轮324条维护入口净增323条，完整库276,799条。
- 当前pose-phrases、ranking-slang及lua-filter-unit报告须匹配当前TSV/原生词典/Lua哈希；旧引擎报告只作baseline。
- 检查Go单元测试、最终EXE隔离安装/回滚及内置文件一致性；用户确认真实输入和新EXE扫描，旧版本结果不得继承。
- 普通打包不重建追溯包；通过`--installer`复用已验收EXE，核对版本、内置方案及许可。上传同一份已验收EXE，方案ZIP内与独立EXE一致；验证ZIP CRC、全部内部哈希及外部SHA256SUMS。
- 发布前提供文件清单，获得本轮明确同意；核对git status及git ls-files不含引擎、原始数据库、发布二进制、日志、机器路径或密钥。
- 提交、tag和push后建立草稿Release，附件齐全再公开；公开下载校验哈希，核对README、LICENSE、安装文档和版本。
- 公开核验完成后才标记本轮升级完成并定稿交接；整理旧版本到历史目录，保留最新版本独立目录和必要证据。
