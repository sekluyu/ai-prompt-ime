# GitHub发布检查清单

0.2.2保留原有来源tag，新增通用颜色/配色短语，并将Ctrl＋Shift＋逗号改为空格开关。默认/扩展的引擎回归、通用映射与独立EXE安装测试使用隔离目录；本版未追加维护者实机验收。自有代码采用MIT，默认词库保留成人相关标签，README明确未附实机截图。以下清单用于发布审核；审核状态以维护者确认和实际发布结果为准。

## 维护者审核

- [ ] 阅读README全文：产品名称、说明、操作及词库数字确认无误。
- [ ] 确认根目录MIT LICENSE、2026版权行与开发署名一致。
- [ ] 确认默认词库含成人相关标签的公开范围。
- [ ] 如附候选框/实际输入截图，使用真实截图且不含个人信息；未附时README如实说明。
- [ ] 确认验收反馈是否需要公开的简短记录；没有逐项证据的内容不扩写成全量保证。

## 仓库与附件

- [ ] 看首个commit的文件清单与差异，确认只有方案、默认词库、脚本、测试、docs、README与第三方许可。
- [ ] 核对仓库工作目录和.git总计仍小于20MB；确认dictionary、validation、fixtures、dist、pydeps、引擎二进制/PDB/7z和缓存未跟踪。
- [ ] 检查敏感信息；不要提交账号令牌、个人配置、机器运行日志或私有路径报告。
- [ ] 确认两个独立EXE、默认/扩展/数据三个ZIP及SHA256SUMS.txt在本地附件归档中；旧附件不因README更新就视为已同步，公开前重建并重新核对说明、许可、版本与校验值。
- [ ] Release附件保留ffdkj MIT原文和Go运行时声明；独立EXE内可用--license查看。不夹带Weasel/librime二进制。
- [ ] 核对所有将推送提交的作者与提交者，使用维护者确认的Git身份，不保留占位身份。

## 审核通过后才执行

- [ ] 维护者明确允许创建远程仓库，选定仓库名称、可见性及许可证。
- [ ] 创建远程仓库，设置remote，检查将推送的分支与提交，再在批准范围内push。
- [ ] 创建版本Release，上传两个独立EXE、三个ZIP和SHA256SUMS.txt，核对README中的实际下载链接。
- [ ] 从公开页面抽查README和附件链接，确认最终内容与审核版本一致。
