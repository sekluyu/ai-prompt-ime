# 腿和脚放在什么位置

以下左右均指角色自身的左右，不是画面左右。腿和脚分别描述；“左腿放桌上”不会转换成“左脚放桌上”。

## 输入方法

可以用“左腿／右腿／双腿”“左脚／右脚／双脚”，也可以用“一条腿／另一条腿”“一只脚／另一只脚”。

位置包括桌子、椅子、凳子、沙发、床、地面、台阶、石头、脚凳、长椅、窗台和栏杆。

支持“放……上”“放在……上”“放……上面”“放在……上面”“搭在……上”“搁在……上”。桌子、椅子、凳子和地面还有“桌、椅、凳、地”的简称。

| 中文例子 | 拼音 | 英文输出 |
|---|---|---|
| 左腿放在桌子上面 | `zuotuifangzaizhuozishangmian` | `left leg resting on the table, ` |
| 右腿放沙发上 | `youtuifangshafashang` | `right leg resting on the sofa, ` |
| 左脚放凳子上 | `zuojiaofangdengzishang` | `left foot resting on the stool, ` |
| 右脚放地上 | `youjiaofangdishang` | `right foot resting on the floor, ` |
| 双脚放在床上 | `shuangjiaofangzaichuangshang` | `both feet resting on the bed, ` |
| 左腿搭在右膝盖上 | `zuotuidazaiyouxigaishang` | `left leg resting across right knee, ` |
| 右腿搭在左膝盖上 | `youtuidazaizuoxigaishang` | `right leg resting across left knee, ` |

左右两侧位置不同，可以分别选词，也有“左脚放凳子上右脚放地上”等四个完整组合。

本次新增 128 种英文表达、1364 条中文拼音映射。中文别名用于查找同一句英文，不计作不同动作。所有短语在构建时写入词库，不在输入时拼接，也不支持把任意物体填进占位符。

这些是描述性姿态短语，绘图模型可能仍会画反左右，或忽略支撑物。复杂姿势可配合姿态控制工具使用。
