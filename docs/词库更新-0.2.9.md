# v0.2.9 词库更新

这次主要修正拼音和中文入口，并增加常用提示词组合。

原始来源快照保留不动，修正规则单独保存在 `data/term_corrections.tsv`，补充词在 `data/expanded_prompts.tsv`。每次重建都会应用这些规则，避免旧错误重新出现。

## 常用组合

输入 `zhengmian` 或 `fumian` 后选择需要的组合；也可以输入完整名称的拼音。默认追加一次逗号和空格。

| 名称 | 专用拼音 | 完整英文 |
|---|---|---|
| 基础正面 | `jichuzhengmian` | `high quality, best quality, ultra-detailed, fine details, sharp focus, ` |
| 动漫正面 | `dongmanzhengmian` | `masterpiece, best quality, high quality, detailed illustration, clean lineart, detailed shading, ` |
| 写实正面 | `xieshizhengmian` | `high quality, photorealistic, fine details, realistic textures, natural lighting, sharp focus, ` |
| 兽人毛发 | `shourenmaofa` | `detailed fur, soft fur, fur texture, fine fur strands, natural fur shading, ` |
| 自然肌肉 | `ziranjirou` | `natural body proportions, natural muscle definition, natural-looking abdominal muscles, subtle muscle shading, ` |
| 基础负面 | `jichufumian` | `worst quality, low quality, lowres, blurry, jpeg artifacts, bad anatomy, bad proportions, extra limbs, missing limbs, extra fingers, missing fingers, fused fingers, watermark, signature, text, ` |
| 身体结构负面 | `shentijiegoufumian` | `bad anatomy, bad proportions, deformed body, malformed limbs, extra limbs, missing limbs, disconnected limbs, fused limbs, bad hands, bad feet, ` |
| 腹肌负面 | `fujifumian` | `bad abs, deformed abdominal muscles, asymmetrical abdominal muscles, overdefined abdominal muscles, ` |

质量词和描述短语不适用于所有模型。腹肌、自然肌肉组合尚未做不同模型的出图效果对比。
