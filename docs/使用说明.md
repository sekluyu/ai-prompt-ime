# 使用说明

切到小狼毫的“绘画提示词”方案，输入连续小写无声调拼音；ü输入v，例如lvse。看候选中的英文tag和中文释义，按空格选首项，或按数字选对应项；`=`下一页，`-`上一页，Esc取消当前拼音。逐个词选择，首版不自动理解整句中文。

默认每个tag末尾补英文逗号和空格；Ctrl+Shift+逗号切换“纯标签/逗号分隔”。最终提示词末尾的逗号空格可删掉。SD提示词中的字面括号会转义，例如 `watercolor_\(medium\)`；英文下划线保留，不转换成中文。

`shuangmawei`→twintails；`guoxiwa`→thighhighs；`baifa`、`baitoufa`、`baimao`→white_hair。不同中文别名可能显示同一个中文主释义；同音不同tag需要看英文选词。找不到词时切回普通中文手动处理，不会调用LLM或联网翻译。

日常聊天通过方案菜单切回原中文方案；绘画方案不会根据窗口/网址自动启停。中文释义和热度不代表模型保证支持，SDXL/Pony优先只是产品方向；具体模型效果由老板按人工清单验证。源数据含人物、作品及成人相关标签，默认常用库也未做成人内容筛除；需要内容筛选时另定规则。
