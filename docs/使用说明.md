# 使用说明

切到小狼毫的“绘画提示词”方案，输入连续小写无声调拼音；ü输入v，例如lvse。看候选中的英文tag或通用短语及中文释义，按空格选首项，或按数字选对应项；`=`下一页，`-`上一页，Esc取消当前拼音。逐个词选择，不自动理解任意整句中文。

## 逗号后的空格开关

默认每次选词后补英文逗号和一个空格。按 **Ctrl＋Alt＋F9**，只切换“是否在逗号后添加空格”，不会关闭逗号：

| 状态 | 连续选择黄色、白色后的输出 |
|---|---|
| 默认开启空格 | `yellow, white, ` |
| 关闭空格 | `yellow,white,` |

再按一次恢复添加空格。最终提示词末尾多余的逗号/空格可手动删掉。0.2.3将快捷键改为Ctrl＋Alt＋F9，避开网页端的Ctrl＋Shift＋逗号冲突。0.2.2的旧组合键也只切换空格，更早版本才同时切换逗号和空格。

SD提示词中的字面括号会转义，例如 `watercolor_\(medium\)`；英文下划线保留，不转换成中文。

## 颜色与配色短语

0.2.2增加基础颜色与双色配色；0.2.3扩展至25种颜色及皮毛配色。颜色候选注释标为“〔通用短语〕”，不冒充Danbooru规范标签。支持红、橙、黄、绿、青、蓝、紫、粉、黑、白、灰、棕、金、银；另支持粉红、褐的别名。

| 输入拼音 | 输出内容（未显示自动附加的分隔符） |
|---|---|
| huang / huangse | `yellow` |
| bai / baise | `white` |
| huangbaipeise | `yellow and white color scheme` |
| heibaipeise | `black and white color scheme` |
| lanbaipeise | `blue and white color scheme` |
| fenseyubaise | `pink and white color scheme` |

双色可按相同方式组合，例如“黄色白色配色”“黄色与白色”；输出顺序跟随输入。无分隔拼音可能有歧义，例如jinhuanghepeise可表示金黄＋褐或金＋黄褐，需要看英文选择；可改用带“色”的完整拼音区分。它们是固定的本地英文短语，未验证任意模型对配色的遵循效果，不提供整句翻译。

`shuangmawei`→twintails；`guoxiwa`→thighhighs；`baifa`、`baitoufa`、`baimao`→white_hair。不同中文别名可能显示同一个中文主释义；同音不同tag需要看英文选词。找不到词时切回普通中文手动处理，不会调用LLM或联网翻译。

日常聊天通过方案菜单切回原中文方案；绘画方案不会根据窗口/网址自动启停。中文释义和热度不代表模型保证支持，不按模型版本屏蔽词条；具体模型效果由老板按人工清单验证。源数据含人物、作品及成人相关标签，默认常用库也未做成人内容筛除；需要内容筛选时另定规则。

**负面词要自行输入到绘图软件的负面提示词框。** 输入法不识别正面/负面框，也不保证质量词一定改善图片；无需先指定模型才能检索这些词。趾行与跖行等同音词须看英文手选。

## 重复候选的处理

当前完整词库为唯一默认，共276,472条映射。同一拼音对应相同最终英文时合并成一条，保留较高权重和维护的中文类别；不同中文/拼音入口继续保留。候选列表按最终英文去重，包括多个别名补全和后续分页；保留先出现的候选及其注释/排序。

`white_hair`与`white hair`等不同写法目前仍保留，不按相近含义、大小写或标点自动合并。此轮只清除完全相同的英文，不减少原有可检索内容。实际候选表现由维护者验收，自动检查不代替实机输入。
