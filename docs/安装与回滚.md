# 安装与回滚 · v0.2.8

先安装Windows小狼毫，本项目只添加绘画提示词方案。普通用户使用独立EXE，不需要Python、Go、.NET、联网或管理员权限。

## 安装

1. 从[v0.2.8 Release](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.8)下载ai-prompt-ime-0.2.8-setup.exe，对照SHA256SUMS.txt核对。也可解压方案ZIP，使用相同内容的“安装绘画提示词.exe”。
2. 双击运行。默认用户目录为`%APPDATA%\Rime`，先备份同名文件及default.custom.yaml，再复制更新。
3. 看到安装成功后，在小狼毫托盘选择“重新部署”。部署完成后按F4选择“绘画提示词”，用shuangmawei检查输出。

自定义用户目录：

```powershell
.\ai-prompt-ime-0.2.8-setup.exe --user-dir "你的Rime用户目录"
```

本版管理五个方案文件：booru.schema.yaml、booru.dict.yaml、booru.tsv、booru.annotations.tsv、lua/booru_filter.lua，加上default.custom.yaml共六个文件。索引与Lua必须对应，不能只替换Lua。

安装器不重启输入法服务、不自动重新部署，不修改其他方案或weasel.custom.yaml。遇到不支持的default.custom.yaml布局时拒绝安装，保留原配置，不要清空配置强行安装。

## 回滚

```powershell
.\ai-prompt-ime-0.2.8-setup.exe --rollback-latest
```

自定义目录带同一个--user-dir；指定备份可用--rollback "完整manifest.json路径"。成功后手动重新部署。

本版备份format_version=2；可回滚到v0.2.6并继续处理旧备份链。不能使用旧EXE回滚新格式备份。安装后被手动修改的文件会触发冲突拒绝，需先核对并处理差异。保留Rime用户目录下booru-backups，不作为垃圾清理。

## 手动安装

复制前保留上述五个同名方案文件与default.custom.yaml的原状态；只复制ZIP内rime目录中的五个方案文件，不覆盖整个lua目录。按原有配置格式把booru加入方案列表，再重新部署。手动安装须按自己留存的原状态恢复，不能借用旧EXE的备份清单。
