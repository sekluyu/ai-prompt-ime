# 安装与回滚

版本0.2.0，已完成维护者的Windows小狼毫本机实机验收。这是基于Windows小狼毫（Rime）扩展的提示词输入方案；使用者需先自行安装[小狼毫](https://github.com/rime/weasel/releases)，并确认能正常输入中文。本包只挂载绘画方案，不安装/替换小狼毫。

## 安装默认词库

1. 将 `ai-prompt-ime-0.2.0.zip` 完整解压到自己选定的固定目录。不要在压缩包内运行。打开该文件夹，应同时看到rime、tools、docs、LICENSE和SHA256SUMS.txt。
2. 安装Python 3并启用PATH，确认 `py -3` 或 `python` 可用。双击解压目录的 **`安装绘画提示词.exe`** 即可调用安装器；它仍需Python 3，不能单独复制EXE使用，不需要以管理员身份运行。启动器源码为 `tools/install_launcher.cs`。也可以在该文件夹空白处右键“在终端中打开”（PowerShell），运行以下命令；源码ZIP使用此方式：

```powershell
python .\tools\install.py --user-dir "$env:APPDATA\Rime"
```

3. 看到 `Installed scheme files only` 才算文件复制完成。记录打印的 `Backup / rollback manifest` 路径。每次安装都先备份同名文件和default.custom.yaml，备份保留在用户目录booru-backups下；不会删除原中文方案、用户词库、weasel.custom.yaml，也不会重启服务。自定义Rime用户目录时，将命令最后一项换成实际路径。
4. 在托盘小狼毫图标右键选“重新部署”，等结束；切到小狼毫后按 **Ctrl+反引号**（通常是Esc下面的键）打开方案菜单，选择“绘画提示词”。热键若被自行改过，用自己的方案选择热键。开始执行《人工验收清单》。

若出现 `Unrecognized default.custom.yaml layout`：安装器未开始写入，保留原文件和完整报错交给GPT修正，不要自行清空配置。若部署失败，回报报错；可按下面回滚。若出现系统权限/文件占用错误，不把失败当成功，保留打印的备份路径。

## 回滚最近一次挂载/更新

先保存当前编辑的文本，然后在同一个解压目录PowerShell执行：

```powershell
python .\tools\install.py --user-dir "$env:APPDATA\Rime" --rollback-latest
```

看到 `Restored managed files` 后，托盘右键“重新部署”，切回普通中文方案检查。该命令只撤销最近一次由安装器写入的5个文件；首次安装会删除其新增文件，更新则恢复上一版。较早备份可以按安装时打印的manifest路径执行：

```powershell
python .\tools\install.py --rollback "这里替换为完整的manifest.json路径"
```

如果挂载后手工改过或删过被管理文件，回滚会拒绝覆盖，显示具体文件；保留现状和备份路径回报GPT合并，别强行删除。booru-backups保留；build内可能留有已编译booru缓存，回滚恢复方案列表后不再启用，不为清理缓存删除原用户数据。这里的回滚不卸载小狼毫。

## 可选扩展包与核对

默认包20002个独立tag、20063条映射；扩展 `ai-prompt-ime-0.2.0-searchable.zip` 有81359个tag、81420条映射，包含更多人名/作品等，候选更杂。两包都是同一个booru方案，互相替换，不要一起叠加；先验收默认包。如要切换，解压扩展包后运行同样安装命令并重新部署，回滚可恢复原默认版。

每包SHA256SUMS.txt记录相对路径与SHA-256；dist/SHA256SUMS.txt记录ZIP校验值。需要核对ZIP时执行 `Get-FileHash .\ai-prompt-ime-0.2.0.zip -Algorithm SHA256`，与dist清单对照。本项目源目录的 `tools/install.py` 也能用，但请优先从版本包执行，以保证说明、方案与词库一致。
