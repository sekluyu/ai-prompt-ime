# 安装与回滚

这是基于 Windows 小狼毫（Rime）扩展的绘画提示词输入方案。先自行安装[小狼毫](https://github.com/rime/weasel/releases)，确认能正常输入中文；本项目不安装或替换小狼毫。

0.2.3 的独立安装器适用于 Windows 10/11 x64，方案和词库内置在 EXE 中，**无需安装 Python、.NET、Go 或其他运行环境，无需联网，不需要管理员权限**。原有 tag 数据保留，另加通用颜色/配色短语；本版使用 librime 和隔离目录自动测试，未追加维护者实机验收。

本文件描述0.2.3独立安装器，完整词库为唯一默认。下载见[v0.2.3 Release](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.3)。

## 安装完整词库

1. 从Release下载 `ai-prompt-ime-0.2.3-setup.exe`。单独这个文件即可安装，无须旁边另放脚本或词库。也可完整解压默认 ZIP，使用根目录的 `安装绘画提示词.exe`，功能相同。
2. 双击 EXE。安装器默认使用 `%APPDATA%\Rime`，先备份同名方案文件及 `default.custom.yaml`，再添加方案。窗口显示“【安装成功】绘画提示词文件已复制到小狼毫用户文件夹。”，同时显示实际版本和词库类型。**这表示文件已安装，还需要下一步重新部署才会生效。** 安装前状态的备份清单路径在提示末尾，按 Enter 关闭窗口。
3. 右键托盘小狼毫图标，选择“重新部署”。部署完成后切到小狼毫，按 F4 打开方案菜单，选择“绘画提示词”；F4 被占用时可用 Ctrl＋反引号，自定义过热键时以自己的配置为准。
4. 输入 `shuangmawei` 并选词，应得到 `twintails, `。更多行为见《使用说明》。

安装器不重启输入法服务、不自动部署，不删除原中文方案、用户词库或 `weasel.custom.yaml`。备份保留在 Rime 用户目录的 `booru-backups` 下。

## 自定义用户目录

如果修改过小狼毫用户目录，在安装器所在目录打开 PowerShell，明确指定同一个目录：

```powershell
.\ai-prompt-ime-0.2.3-setup.exe --user-dir "这里替换为你的Rime用户目录"
```

ZIP 内 EXE 名为 `安装绘画提示词.exe`，命令中的文件名相应替换即可。路径含空格时保留引号。用 `--help` 查看参数，`--version` 查看版本与完整默认词库标识，`--license` 查看内置许可；这三个选项不写入 Rime 用户目录。

若出现 `Unrecognized default.custom.yaml layout`，说明方案列表格式不受支持；安装器未修改方案文件。保留原配置和完整错误，不要清空配置后强行安装。若出现权限、文件占用或其他错误，不把失败当成功；保留错误信息和已打印的备份路径。

## 回滚最近一次安装

先保存正在输入的文字，在安装器所在目录打开 PowerShell：

```powershell
.\ai-prompt-ime-0.2.3-setup.exe --rollback-latest
```

自定义用户目录时带同一个 `--user-dir`。看到 `Restored managed files` 和“回滚成功”后，右键小狼毫托盘图标重新部署，再切回普通中文方案检查。

回滚只撤销最近一次安装所管理的 5 个文件；首次安装会删除新增文件，更新则恢复上一版。连续安装后，回滚会恢复前一个备份指针，可以继续回滚。较早备份可指定其清单：

```powershell
.\ai-prompt-ime-0.2.3-setup.exe --rollback "这里替换为完整的manifest.json路径"
```

新 EXE 与 0.2.0 Python 安装器使用兼容的备份格式，旧版安装产生的备份可由新 EXE 回滚。若安装后手工修改或删除了被管理文件，回滚会在任何恢复写入前拒绝执行，保留现状并报告冲突；不要强行删除备份。

回滚不卸载小狼毫。`booru-backups` 保留；`build` 内可能留有编译缓存，恢复方案列表后不再启用，不为清理缓存删除其他用户数据。

## 词库范围

完整词库是唯一默认，共276,472条拼音映射，不再提供两种词库版本。安装器为 `ai-prompt-ime-0.2.3-setup.exe`，方案ZIP为 `ai-prompt-ime-0.2.3.zip`。此前安装过扩展版的用户可直接更新同一个booru方案；安装前备份、回滚和重新部署步骤相同。
词库追溯 ZIP 仅用于数据溯源，不需要安装。完整词库保留成人相关标签，未做筛除。

## 校验与源码入口

Release附件的 `SHA256SUMS.txt` 记录一个独立EXE和两个ZIP 的 SHA-256。可运行：

```powershell
Get-FileHash .\ai-prompt-ime-0.2.3-setup.exe -Algorithm SHA256
```

将结果与Release校验清单对照。每个 ZIP 内还提供文件校验清单。

源码仓库保留 `tools/install.py` 作为可选入口，只有使用该脚本时才需要 Python 3：

```powershell
python .\tools\install.py --user-dir "$env:APPDATA\Rime"
python .\tools\install.py --user-dir "$env:APPDATA\Rime" --rollback-latest
```

普通用户使用独立 EXE 即可；Python 词库转换及 Go 编译器仅供开发、重建使用。
