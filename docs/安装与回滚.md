# 安装与回滚

这是基于 Windows 小狼毫（Rime）扩展的绘画提示词输入方案。先自行安装[小狼毫](https://github.com/rime/weasel/releases)，确认能正常输入中文；本项目不安装或替换小狼毫。

0.2.4 的独立安装器适用于 Windows 10/11 x64，方案和词库内置在 EXE 中，**无需安装 Python、.NET、Go 或其他运行环境，无需联网，不需要管理员权限**。原有 tag 数据保留，另加通用颜色/配色短语；本版通过数据、Lua模拟候选、Go单元测试和最终EXE隔离安装/回滚检查，未替维护者完成实机输入验收。

本文件描述0.2.4独立安装器，完整词库为唯一默认。下载见[v0.2.4 Release](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.4)。

> 安全软件兼容提示（2026-11-13）：v0.2.4独立安装器曾被火绒识别为 `TrojanSpy/GameSpy.mw` 并删除，尚未获得厂商复核结论。本次在维护者关闭火绒后完成构建与隔离功能检查，**不代表已解除检测**。旧版本未逐一复测。遇到告警请停止使用被检测的EXE并保留日志；兼容问题计划在v0.2.5跟进。本项目不建议用关闭防护或添加排除项作为安装步骤。

## 安装完整词库

1. 从Release下载 `ai-prompt-ime-0.2.4-setup.exe`。单独这个文件即可安装，无须旁边另放脚本或词库。也可完整解压默认 ZIP，使用根目录的 `安装绘画提示词.exe`，功能相同。
2. 双击 EXE。安装器默认使用 `%APPDATA%\Rime`，先备份同名方案文件及 `default.custom.yaml`，再添加方案。窗口显示“【安装成功】绘画提示词文件已复制到小狼毫用户文件夹。”，同时显示实际版本和词库类型。**这表示文件已安装，还需要下一步重新部署才会生效。** 安装前状态的备份清单路径在提示末尾，按 Enter 关闭窗口。
3. 右键托盘小狼毫图标，选择“重新部署”。部署完成后切到小狼毫，按 F4 打开方案菜单，选择“绘画提示词”；F4 被占用时可用 Ctrl＋反引号，自定义过热键时以自己的配置为准。
4. 输入 `shuangmawei` 并选词，应得到 `twintails, `。更多行为见《使用说明》。

安装器不重启输入法服务、不自动部署，不删除原中文方案、用户词库或 `weasel.custom.yaml`。备份保留在 Rime 用户目录的 `booru-backups` 下。

## 自定义用户目录

如果修改过小狼毫用户目录，在安装器所在目录打开 PowerShell，明确指定同一个目录：

```powershell
.\ai-prompt-ime-0.2.4-setup.exe --user-dir "这里替换为你的Rime用户目录"
```

ZIP 内 EXE 名为 `安装绘画提示词.exe`，命令中的文件名相应替换即可。路径含空格时保留引号。用 `--help` 查看参数，`--version` 查看版本与完整默认词库标识，`--license` 查看内置许可；这三个选项不写入 Rime 用户目录。

若出现 `Unrecognized default.custom.yaml layout`，说明方案列表格式不受支持；安装器未修改方案文件。保留原配置和完整错误，不要清空配置后强行安装。若出现权限、文件占用或其他错误，不把失败当成功；保留错误信息和已打印的备份路径。

## 回滚最近一次安装

先保存正在输入的文字，在安装器所在目录打开 PowerShell：

```powershell
.\ai-prompt-ime-0.2.4-setup.exe --rollback-latest
```

自定义用户目录时带同一个 `--user-dir`。看到 `Restored managed files` 和“回滚成功”后，右键小狼毫托盘图标重新部署，再切回普通中文方案检查。

回滚只撤销最近一次安装所管理的 5 个文件；首次安装会删除新增文件，更新则恢复上一版。连续安装后，回滚会恢复前一个备份指针，可以继续回滚。较早备份可指定其清单：

```powershell
.\ai-prompt-ime-0.2.4-setup.exe --rollback "这里替换为完整的manifest.json路径"
```

新 EXE 与 0.2.0 Python 安装器使用兼容的备份格式，旧版安装产生的备份可由新 EXE 回滚。若安装后手工修改或删除了被管理文件，回滚会在任何恢复写入前拒绝执行，保留现状并报告冲突；不要强行删除备份。

回滚不卸载小狼毫。`booru-backups` 保留；`build` 内可能留有编译缓存，恢复方案列表后不再启用，不为清理缓存删除其他用户数据。

## 词库范围

完整词库为唯一默认，共276,476条映射，不拆小词库与扩展版。旧扩展版用户可直接更新同一booru方案。默认词库保留成人相关标签，未筛除。本次不重新打包原始数据追溯ZIP，固定源数据仍见v0.2.3追溯包，本次新增代码与维护表见v0.2.4源码。

## 校验与源码入口

Release附件的 `SHA256SUMS.txt` 记录一个独立EXE和一个方案ZIP 的 SHA-256。可运行：

```powershell
Get-FileHash .\ai-prompt-ime-0.2.4-setup.exe -Algorithm SHA256
```

将结果与Release校验清单对照。每个 ZIP 内还提供文件校验清单。

源码仓库保留 `tools/install.py` 作为可选入口，只有使用该脚本时才需要 Python 3：

```powershell
python .\tools\install.py --user-dir "$env:APPDATA\Rime"
python .\tools\install.py --user-dir "$env:APPDATA\Rime" --rollback-latest
```

普通用户使用独立 EXE 即可；Python 词库转换及 Go 编译器仅供开发、重建使用。

## 手动安装完整词库

1. 从[v0.2.4 Release](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.4)下载`ai-prompt-ime-0.2.4.zip`与`SHA256SUMS.txt`。用`Get-FileHash .\ai-prompt-ime-0.2.4.zip -Algorithm SHA256`核对后解压；哈希只证明文件一致，不是安全认证。
2. 右键小狼毫托盘图标，打开“用户文件夹”，以实际打开的目录为准。复制前自行留存其中原有的`booru.schema.yaml`、`booru.dict.yaml`、`booru.tsv`、`lua/booru_filter.lua`及`default.custom.yaml`。本轮发布操作没有替使用者修改或备份真实用户目录。
3. 将ZIP中`rime`内前三个文件复制到用户文件夹；将`rime/lua/booru_filter.lua`放入用户文件夹的`lua`目录。只覆盖这四个同名方案文件，不覆盖整个`lua`目录。
4. 编辑用户文件夹中的`default.custom.yaml`：若已有`patch`下的`schema_list`，在原列表中加一项`- {schema: booru}`；若已有`schema_list/+`，在该列表中添加。同一方案不重复添加，保留原方案和其他配置。

如果`default.custom.yaml`原先不存在，可新建：

```yaml
patch:
  schema_list/+:
    - {schema: booru}
```

已有`patch:`但没有方案列表时，在其下加入上例的`schema_list/+`两行，保持缩进，不重复新建`patch:`。已有复杂方案列表时按原格式添加，不用示例覆盖整个配置文件。

5. 保存后右键小狼毫托盘图标，选择“重新部署”。等待结束，按F4打开方案菜单，选择“绘画提示词”；F4被占用时可尝试Ctrl＋反引号，自定义过菜单热键时以自己的配置为准。
6. 输入`shuangmawei`并选词，应得到`twintails, `。检查主词排序及俗称输入，实际输入与网页表现由使用者验收。Ctrl＋Alt＋F9只切换逗号后的空格。

## 手动回滚

恢复复制前留存的上述四个同名方案文件和`default.custom.yaml`，再重新部署。原先不存在、此次才新增的文件，只移除这些对应文件即可；不要删除整个Rime用户目录、`lua`目录或其他方案。已有文件被后续手工修改时，先核对差异再恢复。

本次手动安装不会生成旧EXE的`booru-backups`清单。旧版`--rollback-latest`只用于旧安装器自己管理的那次安装，不能用于回滚本次手动复制；保留原有备份，不要为清理删除它们。

## 数据范围与源码入口

完整词库为唯一默认，共276,476条拼音映射，含成人相关标签，未筛除。固定原始数据追溯可参阅v0.2.3追溯包；本版新增维护表和构建代码见v0.2.4源码。

源码仍提供可选`tools/install.py`安装入口，运行该脚本才需要Python 3。普通用户按上述步骤复制文件，不需要安装Python或Go。源码构建与引擎测试的依赖见[开发与发布](开发与发布.md)。
