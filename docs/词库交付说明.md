本版保留原有ffdkj来源层，另加项目维护的通用颜色/配色层，并更新空格开关。默认/扩展来源层的统计保持下表所列；实际加载库另外加入196条通用英文表达、771条拼音映射，分别为20834条和82191条映射。通用层不计入ffdkj来源记录、覆盖率或异常统计。

来源固定为ffdkj仓库commit `d232b4ee431f13c6f34c7f31c35b937b26bb56c2`。原始SQLite SHA-256：`17305abac098be0c3a268e4bfd676711de4a7690529bdb14d0a6be22ce4a2c35`。仓库URL、时间、依赖版本及其他校验值见dictionary/source.json。

**全量遍历与归档已完成；336155条全部可拼音检索尚未完成。** 不把81359个可检索tag说成全库均已覆盖。异常记录254989条（含同一tag多个事项及重复合并），不是缺失tag数量；自动拼音未逐条人工审读，详细分类/原因见conversion-report.json和exceptions.jsonl。人工核心别名标为本地覆盖，不冒充上游翻译。

只做来源层历史有界自动化验收：默认库及扩展库各取48条固定间隔样本，并检查核心序列、开关/取消/未知码/ASCII透传；官方librime 1.13.1均PASS。隔离目录首次初始化/编译约0.184秒和0.752秒，测试进程峰值工作集约43.2MiB和109.3MiB（包括测试进程/引擎，非小狼毫实际驻留、非UI延迟）。证据见validation/gpt/formal-default-engine.json及formal-full-engine.json。默认较小以减少候选噪声及加载量；不据此宣称实机流畅或逐词正确。实机和模型效果交老板。

原始类别统计：general 53664、artist 155856、copyright 20381、character 105504、meta 750。常用库不等于这些类别的全量，也不是人工精选20000个词。

数据包 `ai-prompt-ime-0.2.2-dictionary.zip` 含固定原始来源、规范化数据、全量/常用TSV、覆盖和异常、转换脚本及版本说明，用于追溯，不用于直接安装。转换依赖pypinyin 0.55.0：在数据包根目录执行 `python -m pip install --target .\tools\pydeps pypinyin==0.55.0`，再执行 `python .\tools\convert_dictionary.py`；构建Rime词典用项目tools/build.py。这里的Python依赖用于词库重建，普通用户使用独立EXE安装不需要Python。更新必须另存来源快照，保留覆盖及旧发布包，先对比变化，不自动更新用户目录。
