# 词库交付说明 0.2.3

当前版本为v0.2.3，完整词库是唯一默认。ffdkj原始来源固定为 commit `d232b4ee431f13c6f34c7f31c35b937b26bb56c2`，原始SQLite SHA-256为 `17305abac098be0c3a268e4bfd676711de4a7690529bdb14d0a6be22ce4a2c35`。原来源层不改写；补充来源见[补充词库来源](补充词库来源.md)。

| 当前构建 | 内部词条键 | 拼音映射 |
|---|---:|---:|
| 完整词库（唯一默认） | 151,471 | 276,472 |
| 补充源合并数据（合入前） | 73,988 | 192,878 |

去重前完整库为276,495条映射；同码同最终英文的23组各合并一条。全部原有“拼音＋最终英文”组合均保留，权重取原重复组最大值；内部键优先保留已有规范标签，中文注释在同权重时优先维护的类别标识。来源快照不变，合并清单另存本地交付目录。

候选过滤器对每次查询的最终上屏文本去重，包含后续分页与别名补全，不跨查询保留状态。384组仅空格/下划线不同的写法仍分别保留，不按近似语义自动删词。内部键数不等于去重英文输出数；ffdkj原81,359个标签／81,420条映射的英文检索覆盖保留，部分重复生成行的内部键/注释/权重可以合并。

原ffdkj共有336,155条记录，其中254,796个标签没有可用中文拼音映射；历史转换曾遍历所有记录，不表示全量可中文检索。大型可再生的 normalized.sqlite、metadata.jsonl 和 exceptions.jsonl 已按本地整理要求清理；保留原始tag.sqlite、entries.tsv、来源与转换报告及覆盖表，可重新生成。

词库追溯ZIP用于数据溯源，不需要安装。包含保留的原始SQLite、TSV、来源/转换说明、项目覆盖、四个补充来源的固定文本快照、许可、转换与构建脚本；不包含已清理的大型中间文件。不要套用旧版约45MiB的大小，具体以本次文件和SHA256SUMS为准。仓库不包含完整dictionary目录或引擎。

去重前的历史基线验证采用真实librime 1.13.1隔离目录，分别检查旧两版48条固定间隔样本与原有核心序列、全部2,356条通用颜色映射、常用质量/皮毛别名、皮毛配色样本、各补充来源样本及实际空格快捷键。基线报告在包内以baseline前缀区分，本轮数据/Lua检查另附报告，不把旧基线当作新候选实际输入验收。报告是输入输出验证，不是逐词人工审读、真实Windows TSF验收或图像质量比较。

重建步骤见[开发与发布](开发与发布.md)；更新来源时另存快照并保留许可，不自动更新用户Rime目录。

来源抽查发现并修复TSV字段含英文双引号时的中文标签解码问题：CSV写入器的外层引号与双引号转义现在由Lua正确还原，避免私有前缀漏出。修复后重跑两版基础与补充词样本，并增加带引号词条抽查；颜色字段全部不带CSV外层引号，已静态验证解码前后相同，因此沿用此前两版全2,356条颜色检查，未重复整轮颜色遍历。

本轮去重版本的数据检查确认所有原有检索/英文组合和最大权重保留；Lua候选模拟单元检查覆盖重复、别名、跨页流、查询重置、空格/下划线区别与分隔设置，不创建Rime会话、不模拟键盘。此前librime报告只作去重前基线，不称本轮实际输入已通过。输入法可用性由维护者验收。
