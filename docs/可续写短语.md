# 可续写的腿脚位置短语

选中后先输出半句话，末尾留一个空格，不加逗号。接着输入具体位置即可，不需要预先把所有物体都加进词库。

| 输入 | 候选 | 输出 |
|---|---|---|
| `zuotuifangzai` | 左腿放在某物上 | `left leg resting on ` |
| `youtuifangzai` | 右腿放在某物上 | `right leg resting on ` |
| `shuangtuifangzai` | 双腿放在某物上 | `both legs resting on ` |
| `zuojiaofangzai` | 左脚放在某物上 | `left foot resting on ` |
| `youjiaofangzai` | 右脚放在某物上 | `right foot resting on ` |
| `shuangjiaofangzai` | 双脚放在某物上 | `both feet resting on ` |
| `yitiaotuifangzai` | 一条腿放在某物上 | `one leg resting on ` |
| `lingyitiaotuifangzai` | 另一条腿放在某物上 | `the other leg resting on ` |
| `yizhijiaofangzai` | 一只脚放在某物上 | `one foot resting on ` |
| `lingyizhijiaofangzai` | 另一只脚放在某物上 | `the other foot resting on ` |

也支持完整的“左腿放在某物上”拼音，`tuifangzai` 和 `jiaofangzai` 分别查“一条腿”和“一只脚”的半句。

例如先选 `zuotuifangzai`，再用输入法选“桌子”（`zhuozi`），会组成 `left leg resting on table, `。如果需要自己输入 `the table`，可以切到英文后补上；若要继续添加其他提示词，再补逗号即可。

左右均指角色自身的左右。普通完整词条仍按原来的逗号和空格设置输出。半句候选始终留一个用于续写的空格。

这是 v0.2.11 新增的输入方式。
