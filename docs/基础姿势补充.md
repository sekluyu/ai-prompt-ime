# 基础姿势补充

“腿放平”表示坐着，腿向前伸直。它不表示把腿悬空抬到水平位置；后者用“腿抬到水平位置”查找。

| 中文 | 拼音 | 英文输出 |
|---|---|---|
| 腿放平 | `tuifangping` | `sitting with legs extended forward, ` |
| 左腿放平 | `zuotuifangping` | `sitting with left leg extended forward, ` |
| 右腿放平 | `youtuifangping` | `sitting with right leg extended forward, ` |
| 双腿放平 | `shuangtuifangping` | `sitting with both legs extended forward, ` |
