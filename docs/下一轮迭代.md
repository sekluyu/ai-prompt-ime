# 下一轮迭代准备

## 当前基线

- 已发布版本：[v0.2.1](https://github.com/sekluyu/ai-prompt-ime/releases/tag/v0.2.1)。发布代码提交：`2dc71dfa405197df1d550cba93fe041aaf042bab`。
- 相对 v0.2.0 的变更见仓库[更新记录](https://github.com/sekluyu/ai-prompt-ime/blob/main/CHANGELOG.md)。当前本轮为待发布0.2.2：已选择增加通用颜色/配色短语，以及将快捷键改为空格开关。下面其他候选事项尚未选择实现。
- 默认与扩展词库分别提供独立 EXE 和完整 ZIP，另有词库追溯 ZIP 与 SHA256SUMS.txt，共六个发布附件。旧版 v0.2.0 保留。
- 普通用户安装无需 Python、.NET 或 Go；只需已安装的小狼毫及 Windows 10/11 x64。词库转换、构建及开发测试仍使用各自的开发依赖。

## 本次已验证

- Go 安装器的配置处理、重复安装、备份链、精确恢复和冲突拒绝单元测试通过。
- 默认及扩展 EXE 均在临时目录单文件、PATH 清空条件下通过安装和回滚测试，内置方案与对应词库逐字节一致。
- 中文、空格和尾反斜杠路径、UTF-8 BOM/CRLF、Python 与原生备份双向回滚通过；不支持的配置、错误参数、手工修改冲突及非法备份文件名会被拒绝。
- 三个 ZIP 的 CRC 和内部 SHA-256 检查通过；ZIP 内 EXE 与单独发布的 EXE 一致。
- 真实 Rime 用户目录未用于安装器自动测试。方案与词库沿用 v0.2.0 的实机验收和引擎测试证据，新安装器未追加维护者实机验收记录。

## 接续工作入口

- 原生安装器：`tools/windows-installer/main.go`；构建入口：`tools/build_windows_installer.py`。
- 安装器单元测试：`tools/windows-installer/main_test.go`；端到端测试：`tests/native_installer_test.py`。
- 原 Python 安装器：`tools/install.py`，保留为可选源码入口及备份兼容参考。
- 三包与独立 EXE 的打包入口：`tools/package_release.py`；数据和开发引擎不在仓库，需要按[开发与发布](开发与发布.md)准备。
- 新一轮开始前检查 `git status`、当前分支与远程差异，保留已有修改；不要改写已发布 tag，不将 EXE、ZIP、全量词库、开发引擎、运行日志或机器路径报告提交进 Git。
- 开发与维护署名沿用当前约定：GPT（Codex）和 DeepSeek 负责开发，sekluyu 负责项目目标、发布决策与本机验收。后续是否协作及具体分工以维护者当次要求为准。
